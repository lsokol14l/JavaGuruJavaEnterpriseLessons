Java EE - это стандартизировннаый набор технологий для разработки сложных корпоративных приложений. 

Сначала у нас был Java Core, на котором мы писали простые относительно небольшие приложения, однако с ростом популярности Java, стали появляться различные
технологии, для написания более сложных систем, их стало настолько много, что компания IBM, решила взвалить на себя ношу, стандратизировать все появившиеся
технологии и выпустить единый стандарт, так и появился Java Enterprise Edition.

Однако когда мы говорим про Java EE, нельзя не упомянуть Spring.
Spring - это фреймворк(набор библиотек), основанный на стандарте Java EE, но не являющийся ее частью, которые позволяет быстро, просто и красиво строить
сложные корпоративные системы и решать бизнес задачи.
Spring настолько сильно набрал популярность, что стал неотъемлимым инструментом Java разработчика и, в последствии писать на чистом Java EE без Spring стали
настолько редко, что Oracle перестал поддерживать Java EE в чистом виде, из-за чего кстати поднялась волна хайпа, типо Java умирает, не в этот раз =)

Далее разработкой Java EE, занялась другая компания Eclipse, однако Oracle, не разрешили им использовать старое название Java EE, так на свет появилась Jakarta EE,
Jakarta - столица Индонезии. Индонезия находится на острове Java. Сейчас Jakarta EE представляет собой простую, мощную и легковесную систему, но все мы пишем на Spring.
