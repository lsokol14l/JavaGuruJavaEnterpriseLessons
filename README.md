# Занятие 5. Apache Tomcat, сервер приложений и контейнер сервлетов

Коротенькое вводное видео, основная суть которого рассказать из каких модулей состит томкат, его возможности, структура, логи и жизненный цикл.
Чисто поверхностно о вохможностях.

Томкат - это веб сервер и контейнер сервлетов, состоит из 3 модулей:

Coyote (HTTP Connector)- модуль который отвечает за получение web запросов, переработку их в CoyoteHttpRequest/CoyoteHttpResponse и передачу в Catalina.

Catalina - модуль который отвечает за умение работать с нашими Java Servlet'ами.

Jasper - модуль который отвечает за работу с JSP.
